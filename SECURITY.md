# Security Policy

## Supported versions

The latest released version of CozyLife Local is supported for security fixes.
Pre-release builds are intended for testing and should be updated to the latest
pre-release before reporting an issue.

## Reporting a vulnerability

Please do not report suspected security vulnerabilities in a public GitHub
issue, discussion, or pull request.

Use GitHub's **Report a vulnerability** button on this repository's Security
page to send a private report to the maintainers. Include the affected version,
steps to reproduce the issue, potential impact, and any proof of concept that
can be shared safely.

The maintainers will acknowledge the report, investigate it privately, and
coordinate a fix and disclosure where appropriate.
